title: Introduction
description: Evaluation and regression testing for LLM applications and AI agents, as a Go library.

Sentinel is a Go library for evaluating LLM applications and AI agents. You write suites of test cases, run them against a model, an agent or any Go function, and score each output. Results are stored, so you can save a baseline and catch the run where a prompt or model change made things worse.

For agents there's a second layer. Besides plain input and output checks, Sentinel has scorers for the things you'd judge a person on: which tools they reached for (**skills**), whether they stayed in character (**traits**), whether a trigger got the right reaction (**behavior**), how they worked through a problem (**cognition**), how they talked (**communication**), what they noticed (**perception**) and whether it all adds up to one **persona**.

It's a library, not a service. You bring the LLM client, the database and, if you want one, the HTTP server.

## The human-like dimensions

| Dimension | What it checks | Scorer | Needs |
|-----------|----------------|--------|-------|
| Skill | Expected tools used, forbidden ones avoided | `skill_usage` | an agent trace |
| Trait | The output shows a personality trait | `trait_consistency` | an LLM client |
| Behavior | A trigger led to the expected tool calls | `behavior_trigger` | an agent trace |
| Cognition | Trace steps follow the expected phases in order | `cognitive_phase` | an agent trace |
| Communication | Tone and format match | `communication_style` | an LLM client |
| Perception | Output mentions what matters and skips distractors | `perception_focus` | nothing |
| Persona | The output fits a persona description | `persona_coherence` | an LLM client |

## What it does

- 20 built-in scorers: nine deterministic ones (exact, contains, not_contains, regex, length, latency, cost, `json_valid`, `json_schema`), four model-graded ones (LLM judge, factual, hallucination, embedding similarity) and the seven above. `scorer.FromFunc` covers your own.
- Targets for a raw LLM call, an agent that returns an execution trace, or any Go function.
- Baselines. Every completed run is compared against the suite's current baseline, and a drop fires a hook.
- Red-team case generators for prompt injection, jailbreaks, system prompt leakage, hallucination and off-topic requests.
- Six scenario generators that write cases aimed at one dimension.
- Multi-model comparison: one suite against several targets with `comparison.Compare`.
- Prompt versions per suite, with one current version that runs use.
- 15 lifecycle hook interfaces, with metrics and audit plugins built in.
- PostgreSQL, SQLite and MongoDB stores through Grove, plus an in-memory store.
- A `forge.Extension` that provides the engine, mounts an HTTP API and registers the dashboard contract.
- Assertions for `go test` in `sentineltest`, and terminal, JSON, HTML and CI reports.

`json_schema` only checks that the output is valid JSON for now; the schema you give it isn't enforced yet. The HTTP API is partial too, see the [HTTP API reference](/docs/api-reference/http-api).

## Design

Sentinel is a set of Go packages you import. You control `main`, the database connection and the process lifecycle.

Targets, scorers, stores, LLM clients and plugins are all interfaces, so you can swap any of them for your own.

`sentinel.WithApp` on the context stamps the app on suites you create, and list filters take an app ID. That's a label and a filter, not access control. See [Multi-Tenancy](/docs/concepts/multi-tenancy).

Every entity has a TypeID: a type prefix (`suite_`, `tcase_`, `erun_`, `eres_`, `base_`, `pver_`) on a sortable UUIDv7.

## Quick look

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/xraph/sentinel/engine"
	"github.com/xraph/sentinel/scorer"
	"github.com/xraph/sentinel/store/memory"
	"github.com/xraph/sentinel/suite"
	"github.com/xraph/sentinel/target"
	"github.com/xraph/sentinel/testcase"
)

func main() {
	ctx := context.Background()

	eng, err := engine.New(engine.WithStore(memory.New()))
	if err != nil {
		log.Fatal(err)
	}

	s := &suite.Suite{Name: "capitals"}
	if err := eng.CreateSuite(ctx, s); err != nil {
		log.Fatal(err)
	}
	if err := eng.CreateCase(ctx, &testcase.Case{
		SuiteID: s.ID, Name: "france", Input: "Capital of France?", Expected: "Paris",
	}); err != nil {
		log.Fatal(err)
	}

	bot := target.FromFunc("bot", func(_ context.Context, _ string) (string, error) {
		return "Paris", nil
	})

	res, err := eng.RunEval(ctx, &engine.RunConfig{
		SuiteID: s.ID,
		Target:  bot,
		Scorers: []scorer.Scorer{&scorer.ExactScorer{}},
	})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("pass rate %.0f%%\n", res.Stats.PassRate*100)
}
```
