title: Plugin System
description: Lifecycle hooks for metrics, audit trails, and custom processing.
---

Sentinel uses an opt-in plugin system: a plugin subscribes to lifecycle events by implementing specific interfaces. The base interface requires only a `Name()` method, and every hook is optional.

## Base interface

```go
type Extension interface {
    Name() string
}
```

## Lifecycle hooks

There are 15 hook interfaces. A plugin implements only the hooks it needs. Two of them, `RedTeamStarted` and `RedTeamCompleted`, are declared but never fired.

### Eval lifecycle

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `EvalRunStarted` | `OnEvalRunStarted(ctx, suiteID, runID, model)` | Evaluation run begins |
| `EvalRunCompleted` | `OnEvalRunCompleted(ctx, suiteID, runID, passRate, elapsed)` | Run ends `completed` |
| `EvalRunFailed` | `OnEvalRunFailed(ctx, suiteID, runID, err)` | Run ends `failed` (results couldn't be stored or read). A cancelled run fires neither |

### Case lifecycle

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `CaseStarted` | `OnCaseStarted(ctx, runID, caseID)` | Case evaluation begins |
| `CaseCompleted` | `OnCaseCompleted(ctx, runID, caseID, score, elapsed)` | Case was scored, whatever its status |
| `CaseFailed` | `OnCaseFailed(ctx, runID, caseID, err)` | The target returned an error. Scorer errors don't fire it |

### Regression

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `RegressionDetected` | `OnRegressionDetected(ctx, suiteID, baselineID, delta)` | A completed run fell below the current baseline. `delta` is the worst drop, a negative number |

### Baseline

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `BaselineSaved` | `OnBaselineSaved(ctx, suiteID, baselineID)` | Baseline saved |

### Red team

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `RedTeamStarted` | `OnRedTeamStarted(ctx, suiteID, attackCount)` | Never fired yet |
| `RedTeamCompleted` | `OnRedTeamCompleted(ctx, suiteID, bypassCount, elapsed)` | Never fired yet |

### Persona evaluation

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `PersonaEvalStarted` | `OnPersonaEvalStarted(ctx, runID, personaName)` | A run with a `PersonaRef` begins |
| `PersonaEvalCompleted` | `OnPersonaEvalCompleted(ctx, runID, personaName, dimensions)` | A run with a `PersonaRef` completes |

### Prompt versioning

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `PromptVersionCreated` | `OnPromptVersionCreated(ctx, suiteID, pvID, version)` | Prompt version created |

### Comparison

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `ComparisonCompleted` | `OnComparisonCompleted(ctx, suiteID, models, elapsed)` | `comparison.Compare` finishes |

### Shutdown

| Interface | Method | When it fires |
|-----------|--------|---------------|
| `Shutdown` | `OnShutdown(ctx)` | `engine.Stop`, before the store closes |

## Registry

You register plugins with `engine.WithExtension` (or `extension.WithExtension` in a Forge app). The engine keeps them in a `plugin.Registry`, which sorts each plugin into the hooks it implements at registration, so an event only calls the plugins that implement it. `eng.Extensions()` returns the registry.

Hooks run synchronously, in registration order, on the goroutine that raised the event. Case hooks run on the case's worker, so a slow hook slows the run.

## Error handling

A hook's error is logged and otherwise ignored. It never stops the run.

## Built-in extensions

- `observability.MetricsExtension`: unlabelled counters for lifecycle events. The engine records labelled metrics and spans without it, see [Observability](/docs/infrastructure/observability)
- `audithook.Extension`: turns lifecycle events into audit records

## Writing a custom extension

```go
type SlackNotifier struct {
    webhookURL string
}

func (s *SlackNotifier) Name() string { return "slack-notifier" }

func (s *SlackNotifier) OnRegressionDetected(ctx context.Context, suiteID id.SuiteID, baselineID id.BaselineID, delta float64) error {
    return postToSlack(s.webhookURL, fmt.Sprintf("Regression in suite %s: fell %.2f below baseline", suiteID, -delta))
}

// Register:
eng, err := engine.New(
    engine.WithStore(st),
    engine.WithExtension(&SlackNotifier{webhookURL: "https://hooks.slack.com/..."}),
)
```

`postToSlack` is yours. See [Custom Plugin](/docs/guides/custom-plugin) for a fuller example.
