title: Custom Store

Sentinel talks to storage through one Go interface, `store.Store`. This guide shows what a custom backend has to implement.

## The composite interface

Your store must implement the composite `store.Store` interface, which embeds 5 subsystem stores:

```go
import "github.com/xraph/sentinel/store"

type Store interface {
    suite.Store
    testcase.Store
    evalrun.Store
    baseline.Store
    promptversion.Store

    Migrate(ctx context.Context) error
    Ping(ctx context.Context) error
    Close() error
}
```

## Subsystem interfaces

### suite.Store

```go
type Store interface {
    CreateSuite(ctx context.Context, s *Suite) error
    GetSuite(ctx context.Context, suiteID id.SuiteID) (*Suite, error)
    GetSuiteByName(ctx context.Context, appID, name string) (*Suite, error)
    UpdateSuite(ctx context.Context, s *Suite) error
    DeleteSuite(ctx context.Context, suiteID id.SuiteID) error
    ListSuites(ctx context.Context, filter *ListFilter) ([]*Suite, error)
}
```

### testcase.Store

```go
type Store interface {
    CreateCase(ctx context.Context, tc *Case) error
    CreateCaseBatch(ctx context.Context, cases []*Case) error
    GetCase(ctx context.Context, caseID id.CaseID) (*Case, error)
    UpdateCase(ctx context.Context, tc *Case) error
    DeleteCase(ctx context.Context, caseID id.CaseID) error
    ListCases(ctx context.Context, suiteID id.SuiteID) ([]*Case, error)
    CountCases(ctx context.Context, suiteID id.SuiteID) (int64, error)
    ImportCases(ctx context.Context, suiteID id.SuiteID, format string, data []byte) (int64, error)
}
```

`ImportCases` is never called; `engine.ImportCases` parses and writes cases itself. It stays on the interface so existing stores keep compiling, and a stub that returns an error is fine.

### evalrun.Store

```go
type Store interface {
    CreateRun(ctx context.Context, run *Run) error
    GetRun(ctx context.Context, runID id.EvalRunID) (*Run, error)
    UpdateRun(ctx context.Context, run *Run) error
    CancelRun(ctx context.Context, runID id.EvalRunID, at time.Time) (bool, error)
    FinalizeRun(ctx context.Context, runID id.EvalRunID, f *Finalization) (RunState, error)
    ListRuns(ctx context.Context, filter *ListFilter) ([]*Run, error)
    ListRunsBySuite(ctx context.Context, suiteID id.SuiteID) ([]*Run, error)
    CreateResult(ctx context.Context, result *Result) error
    CreateResultBatch(ctx context.Context, results []*Result) error
    ListResults(ctx context.Context, runID id.EvalRunID) ([]*Result, error)
    GetResultStats(ctx context.Context, runID id.EvalRunID) (*ResultStats, error)
}
```

`CancelRun` and `FinalizeRun` carry the run's state machine, and the condition has to be part of the write so two replicas can't race:

- `CancelRun` sets the state to `cancelled` only if it's still `running`. It returns `false` with no error when the run exists but isn't running.
- `FinalizeRun` writes the counters, dimension scores, completion time and error, but changes the state only if it's still `running`. It returns the state the store holds afterwards, so a cancel that arrived first wins.

`GetResultStats` computes the aggregates from the stored results: `PassRate` is passed over total, so errors count against it.

### baseline.Store

`SaveBaseline` with `IsCurrent` set must clear the flag on the suite's other baselines, and `GetLatestBaseline` returns the current one (or `sentinel.ErrBaselineNotFound`).

```go
type Store interface {
    SaveBaseline(ctx context.Context, b *Baseline) error
    GetBaseline(ctx context.Context, baselineID id.BaselineID) (*Baseline, error)
    GetLatestBaseline(ctx context.Context, suiteID id.SuiteID) (*Baseline, error)
    ListBaselines(ctx context.Context, suiteID id.SuiteID) ([]*Baseline, error)
    DeleteBaseline(ctx context.Context, baselineID id.BaselineID) error
}
```

### promptversion.Store

```go
type Store interface {
    CreatePromptVersion(ctx context.Context, pv *PromptVersion) error
    GetPromptVersion(ctx context.Context, pvID id.PromptVersionID) (*PromptVersion, error)
    ListPromptVersions(ctx context.Context, suiteID id.SuiteID) ([]*PromptVersion, error)
    GetCurrentPromptVersion(ctx context.Context, suiteID id.SuiteID) (*PromptVersion, error)
    SetCurrentPromptVersion(ctx context.Context, suiteID id.SuiteID, pvID id.PromptVersionID) error
}
```

## Contract details

- Return the root package's not-found errors (`sentinel.ErrSuiteNotFound`, `sentinel.ErrRunNotFound` and so on) for a missing row, unwrapped or wrapped with `%w`. The engine and the HTTP API check them with `errors.Is`.
- An empty `AppID` in a list filter matches every app.
- Suite names are unique per app, and prompt version numbers are unique per suite.
- `Migrate` is called once before first use and may be called again on every start, so make it idempotent.

## Compile-time check

```go
var _ store.Store = (*MyStore)(nil)
```

## Conformance suite

`store/storetest` is the suite every built-in backend passes. Run it against yours:

```go
func TestConformance(t *testing.T) {
    storetest.Run(t, func(t *testing.T) store.Store {
        t.Helper()
        s := NewMyStore() // a fresh, migrated, empty store per subtest
        return s
    })
}
```

## Registering with the engine

```go
eng, err := engine.New(engine.WithStore(&MyStore{}))
```

## Reference implementations

| Backend | Package | Notes |
|---------|---------|-------|
| Memory | `store/memory` | Maps behind an RWMutex, the simplest reference |
| SQLite | `store/sqlite` | Grove with `sqlitedriver`, migrations in Go |
| PostgreSQL | `store/postgres` | Grove with `pgdriver`, migrations in Go |
| MongoDB | `store/mongo` | Grove with `mongodriver`, conditional updates instead of transactions |
