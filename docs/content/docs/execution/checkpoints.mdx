title: Baselines & Regression Detection
description: Save a known-good run as a baseline and get told when a later run falls below it.
---

A **baseline** is a snapshot of a run you're happy with. Every later run of the suite that completes is compared against the current baseline, and a drop fires a hook.

## Baseline

```go
type Baseline struct {
    ID              id.BaselineID
    SuiteID         id.SuiteID
    RunID           id.EvalRunID
    Name            string
    Results         []Result // baseline.Result, one per case
    PassRate        float64
    AvgScore        float64
    DimensionScores map[string]float64
    IsCurrent       bool
    CreatedAt       time.Time
}
```

## baseline.Result

Per-case scores for comparison:

```go
type Result struct {
    CaseID          id.CaseID
    CaseName        string
    Score           float64
    Status          string
    DimensionScores map[string]float64
}
```

## Creating a baseline

Copy the run's stats and its results:

```go
b := &baseline.Baseline{
    SuiteID:         res.Run.SuiteID,
    RunID:           res.Run.ID,
    Name:            "v2.1-release",
    PassRate:        res.Stats.PassRate,
    AvgScore:        res.Stats.AvgScore,
    DimensionScores: res.Stats.DimensionScores,
    IsCurrent:       true,
}
for _, r := range res.Results {
    b.Results = append(b.Results, baseline.Result{
        CaseID:          r.CaseID,
        CaseName:        r.CaseName,
        Score:           r.Score,
        Status:          string(r.Status),
        DimensionScores: r.DimensionScores,
    })
}
if err := eng.SaveBaseline(ctx, b); err != nil {
    log.Fatal(err)
}
```

Saving with `IsCurrent: true` clears the flag on the suite's other baselines, so there's one current baseline per suite. `GetLatestBaseline` returns that current one, not simply the newest; with none current it returns `ErrBaselineNotFound`. A baseline without `Results` still compares pass rate, average score and dimensions, but reports every case as new.

The HTTP route `POST /v1/suites/:suiteId/baselines` with `{"run_id": "...", "name": "..."}` does this copy for you from a stored run and makes the new baseline current.

## Regression detection

You don't have to ask for it. When a run completes, the engine loads the suite's current baseline and calls `baseline.DetectRegression` with the run's `regression_threshold` (0.05 by default). One absolute threshold covers everything, and lower is always worse:

- Pass rate fell by more than the threshold.
- Average score fell by more than the threshold.
- A dimension score fell by more than the threshold, or a dimension the baseline has wasn't measured at all.
- A case's score fell by more than the threshold.

If any of those hold, `OnRegressionDetected` fires with the worst delta (a negative number). With no current baseline there's nothing to compare, which counts as neither a pass nor a regression. Cancelled and failed runs aren't compared.

```go
type RegressionDetected interface {
    OnRegressionDetected(ctx context.Context, suiteID id.SuiteID, baselineID id.BaselineID, delta float64) error
}
```

To check a run yourself, for example to fail a CI job:

```go
b, err := eng.GetLatestBaseline(ctx, suiteID)
if err != nil {
    log.Fatal(err)
}
rr := baseline.DetectRegression(res.Stats, res.Results, b, 0.05)
if rr.HasRegression {
    fmt.Printf("worst drop %.2f, %d cases regressed\n", rr.WorstDelta(), len(rr.RegressedCases))
}
```

`RegressionResult` also lists `MissingCases` (in the baseline, not in the run) and `NewCases` (in the run, not in the baseline). Neither sets `HasRegression`, since the suite changed. `MissingDimensions` does.

`comparison.Diff(current, baseline *evalrun.ResultStats)` gives you plain deltas between two sets of stats, without a verdict.

## Engine methods

```go
eng.SaveBaseline(ctx, baseline)
eng.GetBaseline(ctx, baselineID)
eng.GetLatestBaseline(ctx, suiteID) // the current one
eng.ListBaselines(ctx, suiteID)
eng.DeleteBaseline(ctx, baselineID)
```

## API routes

Under `base_path` plus `/v1` (`/sentinel/v1` by default):

| Method | Path | Status |
|--------|------|--------|
| `POST` | `/suites/:suiteId/baselines` | Works. Body: `{"run_id": "erun_...", "name": "v1"}` |
| `GET` | `/baselines/:baselineId` | Works |
| `GET` | `/suites/:suiteId/baselines` | Doesn't register against Forge v1.12.7 (405, since `POST` shares the path) |
| `POST` | `/suites/:suiteId/runs/with-baseline` | A stub that answers 400, and it doesn't register either (404) |
