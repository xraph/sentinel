---
title: Entities
description: The core data types in Sentinel, from suites and cases to runs, results, baselines and prompt versions.
---

Every Sentinel entity carries a TypeID identifier. Suites, cases, runs and results also embed the `sentinel.Entity` base type for their timestamps.

## Base entity

```go
type Entity struct {
    CreatedAt time.Time `json:"created_at"`
    UpdatedAt time.Time `json:"updated_at"`
}
```

`Suite`, `Case`, `Run` and `Result` embed it. `Baseline` and `PromptVersion` have their own `CreatedAt` and no `UpdatedAt`.

## Entity overview

### Suite

A suite groups related test cases together with a shared system prompt, model, and optional persona reference.

```go
type Suite struct {
    sentinel.Entity
    ID           id.SuiteID
    Name         string
    Description  string
    AppID        string
    SystemPrompt string
    Model        string
    Temperature  float64
    PersonaRef   string         // optional agent persona name
    Metadata     map[string]any
}
```

### Case

A test case defines a single evaluation scenario with input, expected output, scenario type, and scorer configuration.

```go
type Case struct {
    sentinel.Entity
    ID           id.CaseID
    SuiteID      id.SuiteID
    Name         string
    Input        string
    Expected     string
    ScenarioType ScenarioType   // standard, skill_challenge, trait_probe, etc.
    Scorers      []ScorerConfig
    Tags         []string
    Context      map[string]any
    Metadata     map[string]any
}
```

`ScenarioType` defaults to `standard`. See [The Human Model](/docs/human-model/overview) for the other seven.

### EvalRun

An evaluation run records the execution of a suite against a target:

```go
type Run struct {
    sentinel.Entity
    ID              id.EvalRunID
    SuiteID         id.SuiteID
    Model           string
    SystemPrompt    string
    Temperature     float64
    TotalCases      int
    Passed          int
    Failed          int
    PassRate        float64
    AvgScore        float64
    AvgLatencyMs    int
    TotalTokens     int
    TotalCost       float64
    AppID           string
    TargetTenantID  string
    PersonaRef      string
    Config          map[string]any  // the run's settings: thresholds, target, scorers, model, prompt version
    State           RunState        // running, completed, failed, cancelled
    Error           string
    CompletedAt     *time.Time
    DimensionScores map[string]float64
}
```

### EvalResult

The outcome of evaluating a single test case within a run:

```go
type Result struct {
    sentinel.Entity
    ID              id.EvalResultID
    RunID           id.EvalRunID
    CaseID          id.CaseID
    CaseName        string
    Status          ResultStatus    // pass, fail, error
    Score           float64
    Output          string
    LatencyMs       int
    TokensUsed      int
    Cost            float64
    ScorerResults   []ScorerResult
    Error           string
    DimensionScores map[string]float64
    RunTrace        *RunTrace       // optional agent execution trace
}
```

### Baseline

A snapshot of a known-good evaluation run for regression detection:

```go
type Baseline struct {
    ID              id.BaselineID
    SuiteID         id.SuiteID
    RunID           id.EvalRunID
    Name            string
    Results         []baseline.Result // per-case scores copied from the run
    PassRate        float64
    AvgScore        float64
    DimensionScores map[string]float64
    IsCurrent       bool
    CreatedAt       time.Time
}
```

### PromptVersion

A versioned system prompt. `CreatePromptVersion` numbers versions per suite, and a run uses the current version's prompt in place of the suite's:

```go
type PromptVersion struct {
    ID           id.PromptVersionID
    SuiteID      id.SuiteID
    Version      int
    SystemPrompt string
    Changelog    string
    IsCurrent    bool
    RunID        string
    PassRate     *float64
    AvgScore     *float64
    CreatedAt    time.Time
}
```

## Entity relationship diagram

```
Suite
  ├── Case[]
  │     └── ScorerConfig[]
  ├── Run[]
  │     ├── Result[]
  │     │     ├── ScorerResult[]
  │     │     └── RunTrace (optional)
  │     └── DimensionScores
  ├── Baseline[]
  │     └── baseline.Result[]
  └── PromptVersion[]
```

## Store interfaces

Each entity type defines its own store interface. These are composed into the single `store.Store` composite:

```go
type Store interface {
    suite.Store         // CreateSuite, GetSuite, GetSuiteByName, ...
    testcase.Store      // CreateCase, CreateCaseBatch, GetCase, ...
    evalrun.Store       // CreateRun, CancelRun, FinalizeRun, ListResults, ...
    baseline.Store      // SaveBaseline, GetBaseline, GetLatestBaseline, ...
    promptversion.Store // CreatePromptVersion, GetPromptVersion, ...

    Migrate(ctx context.Context) error
    Ping(ctx context.Context) error
    Close() error
}
```
