---
title: Behavior Evaluation
description: Check that a trigger in the input led to the right tool calls and wording.
---

Behavior evaluation checks that a condition in the input got the reaction it should: an angry customer gets escalated, a security report gets a ticket. It reads the tool calls in the run trace and the answer text, so the target has to return a trace (see [Traces](/docs/human-model/overview#traces)).

## Scorer: `behavior_trigger`

```go
s := scorer.NewBehaviorTriggerScorer(
	"escalate-angry-customer",
	[]string{"create_ticket"},              // expected tool calls
	[]string{"escalat", "senior", "sorry"}, // trigger keywords in the output
)
```

The score is the share of expected actions found among the trace's tool names. If you gave trigger keywords and none appears in the answer (case-insensitive substring), that share is halved. With no expected actions, the score is 1 when a keyword appears and 0 otherwise. Without a trace the score is 0.

The scorer isn't in the registry by default. To name it on a case, register a factory as shown in the [overview](/docs/human-model/overview#using-the-scorers).

## Scenario: `behavior_trigger`

`scenario.NewBehaviorTriggerGenerator(name, condition, actions)` writes a case that states the condition directly and, when `Count` is 2 or more (the default), a second that only hints at it ("a situation that might relate to ..."). Both name `behavior_trigger` with `behavior_name` and `expected_actions`:

```go
gen := scenario.NewBehaviorTriggerGenerator("security-alert", "the user mentions a vulnerability", []string{"create_ticket"})
cases, err := gen.Generate(ctx, &scenario.GenerateConfig{SuiteID: suiteID.String()})
```

The generated config has no trigger keywords, so a factory built from it scores on actions alone.

## Dimension score

```go
result.DimensionScores["behavior"] // 0.0 to 1.0
```

`sentineltest.BehaviorTriggerRate(min)` asserts on it.

## Use cases

- Check that a support agent opens a ticket when a customer reports a security issue
- Make sure an agent escalates frustrated customers instead of looping on canned answers
