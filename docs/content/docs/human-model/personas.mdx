---
title: Persona Coherence
description: Ask a judge model whether an answer sounds like it came from the persona you describe.
---

Persona coherence is the whole-person check: does this answer feel like it came from the agent you meant to build? A judge model does the checking, so you need an LLM client.

## Scorer: `persona_coherence`

```go
s := scorer.NewPersonaCoherenceScorer(client, "gpt-4o-mini",
	"A senior engineer: patient with juniors, thorough, never rushes a security finding")
```

`client` is a `scorer.LLMClient`. The scorer sends the persona description, the case input, the answer and, when there's a trace, the number of tool calls and steps, to the judge at temperature 0, and asks for a JSON score from 0 to 1 with a reason. It doesn't combine the other dimension scores; it's one more judgement from the model. A client error makes the case `error`.

The scorer isn't in the registry by default. To name it on a case, register a factory as shown in the [overview](/docs/human-model/overview#using-the-scorers).

## Scenario type

`testcase.ScenarioPersonaCoherence` exists as a label, but there's no generator for it. Write these cases yourself: inputs that exercise several dimensions at once, such as a junior developer's first pull request with both a security bug and style problems.

## PersonaRef

A suite and a run can carry a `PersonaRef`, a name for the persona under test:

```go
s := &suite.Suite{
	Name:       "senior-engineer-eval",
	PersonaRef: "senior-engineer",
}
```

A run takes `RunConfig.PersonaRef`, else the suite's. Sentinel records it on the run and fires the `PersonaEvalStarted` and `PersonaEvalCompleted` hooks for runs that have one. It doesn't look anything up from it: no scorer reads it, and it isn't passed to the target. An `AgentTarget` sends the persona you gave `NewAgentTarget`.

## Dimension score

```go
result.DimensionScores["persona"] // 0.0 to 1.0
```

`sentineltest.PersonaCoherence(min)` asserts on it.

## Use cases

- End-to-end checks of a fully configured agent
- Regression tests after you change a persona's prompt
- Comparing two persona configurations for the same role
